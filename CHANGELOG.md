# Changelog

All notable changes to VaultMedic are documented here.

## 0.1.4

* Replaced the hidden readiness wait with an awaited page load and explicit window display.
* Added a native startup error message instead of failing invisibly.
* Disabled hardware acceleration to improve compatibility with problematic Windows graphics drivers.
* Added an unpacked Windows ZIP that bypasses the portable wrapper.
* Added automated startup reliability checks.

## 0.1.3

* Increased the default desktop scale for text, icons, controls, and spacing.
* Raised small labels, badges, helper text, table headings, and drawer copy to readable sizes.
* Increased the default and minimum window dimensions to protect the enlarged layout.
* Added automated readability regression checks.

## 0.1.2

* Reworked the interface into a light monochrome pixel theme.
* Bundled the Pixelify Sans font inside the application.
* Added a custom black and white Windows icon.
* Added verified NSIS installer and portable Windows build configuration.
* Added a Windows GitHub Actions release workflow with SHA256 checksums.
* Added a beginner friendly GitHub publishing guide.
* Added automated interface and release readiness tests.

## 0.1.1

* Added the first monochrome pixel interface.
* Removed dash punctuation from authored interface copy.
* Added automated theme regression checks.

## 0.1.0

* Initial security focused desktop MVP.
